# Dream Visa

Dream Visa 是一个免费开放的签证 DIY 知识站，整理普通护照、签证材料、递签流程和目的地签证指南。

## 本地开发

```bash
pnpm install
pnpm dev
```

## 生产构建

```bash
pnpm build
```

构建结果位于 `docs/.vitepress/dist`。

## GitHub Pages

推送到 `main` 分支后，GitHub Actions 会自动构建并发布网站。部署工作流位于 `.github/workflows/deploy-pages.yml`。

> 本站内容仅供参考，请以使领馆、签证中心和相关主管机关的最新要求为准。
