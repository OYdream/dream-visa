# 普通护照办理指南

> 面向中国内地居民，整理普通护照首次申领、换发与补发的通用要求。  
> **资料整理日期：2026 年 10 月 23 日。具体要求以受理网点和官方平台实时信息为准。**

## 一分钟看懂

| 事项 | 全国通用规则或通常做法 |
|---|---|
| 首次申领 | 通常需要申请人本人到出入境管理窗口办理 |
| 跨省办理 | 普通护照支持全国通办，不必仅为办护照返回户籍地 |
| 收费标准 | 120 元/本，邮寄费用另计 |
| 办理时限 | 户籍地通常 7 个工作日；跨省异地通常 20 日 |
| 护照有效期 | 未满 16 周岁为 5 年；16 周岁及以上为 10 年 |
| 领取方式 | 根据当地服务选择现场领取或邮寄 |

费用、办理时限和有效期可查阅国家移民管理局发布的
[普通护照签发服务指南](https://www.nia.gov.cn/n741445/n741604/n741648/c816419/content.html)。

::: warning 先分清业务类型
**首次申领**通常需要本人到场；符合条件的**换发、补发**可以尝试全程网上办理。两者的办理入口和材料要求不同。
:::

## 首次申领需要准备什么

普通成年居民首次申领时，可以先按下面这份基础清单准备：

| 材料 | 是否需要 | 说明 |
|---|---|---|
| 有效居民身份证 | 必需 | 用于身份核验 |
| 中国公民出入境证件申请表 | 必需 | 按当地流程线上填写或现场填写 |
| 符合标准的出入境证件照片 | 必需 | 照片应符合出入境证件相片标准 |
| 数码相片检测回执 | 视当地要求 | 部分地区要求提前提供，部分网点可以现场采集或审核 |
| 其他证明材料 | 特殊情形需要 | 根据年龄、身份和申请事由确定 |

::: info 户口簿和居住证
普通成年居民首次申领时，不把户口簿和居住证列为默认必备材料。未成年人、特殊身份人员或其他特殊情形，仍可能需要补充材料，请以受理网点要求为准。
:::

## 特殊申请人怎么准备

### 未满 16 周岁

- 由监护人陪同办理。
- 准备申请人的身份证明材料。
- 准备出生证明、户口簿等监护关系证明。
- 准备监护人的身份证或护照等身份证明。
- 监护人无法陪同时，按官方要求准备委托书和陪同人的身份证明。

### 登记备案国家工作人员

除基础材料外，还需要按照人事管理权限，提交所在单位或上级主管单位出具的同意办理出入境证件的意见。

### 现役军人

现役军人适用相应的证件管理和审批规定，材料与普通居民可能不同。办理前应向所属单位和受理机构确认，不直接套用普通成年居民清单。

### 换发或补发

换发、补发的材料与首次申领不同。根据证件到期、签证页用完、损毁、遗失等具体原因，准备原护照或平台、窗口要求的说明材料。

## 通用办理流程

### 1. 查询网点和预约要求

先通过国家移民管理局政务服务平台、当地公安机关出入境管理部门或 **12367** 服务热线确认受理网点。

### 2. 准备材料和照片

按业务类型准备身份证、申请表、照片和相应补充材料，并确认当地是否要求数码照片回执。

### 3. 到窗口提交申请

首次申领通常需要本人到场。现场会进行身份核验，并按规定采集证件照片、指纹和签名信息。

### 4. 审核和缴费

提交申请后等待审核，并按通知缴纳证件费。需要邮寄的，邮寄费用通常另行计算。

### 5. 领取护照

按照受理回执或通知，在指定时间到窗口领取；当地提供邮寄服务时，也可以在申请时选择邮寄。

## 各地办理前必须核实

全国基本规定相同，但服务实施方式会因城市和网点而变化。预约前至少确认以下事项：

- [ ] 是否需要预约，预约入口在哪里
- [ ] 可以选择哪些办证网点
- [ ] 网点工作时间及是否提供周末服务
- [ ] 是否要求数码照片检测回执
- [ ] 能否现场拍照，以及是否收费
- [ ] 当地公布的承诺办理时限
- [ ] 是否支持邮寄，邮费如何计算
- [ ] 本人的业务类型和户籍是否符合全程网办资格

::: tip 最省事的确认方式
拨打 **12367**，说明所在城市、户籍地、首次申领还是换发补发，再询问预约和照片要求。这样比照搬其他城市的攻略更可靠。
:::

## 网上换发、补发

普通护照换发、补发全程网办目前为试点服务，已经扩大至 **50 个试点城市**。它不适用于首次申领，也不代表居住在试点城市就一定具备资格。

申请人通常需要同时满足：

- 已满 16 周岁；
- 户籍属于试点城市；
- 申请时人在中国境内，不含港澳台地区；
- 此前申领出入境证件时已经留存指纹；
- 非登记备案国家工作人员和现役军人；
- 符合普通护照换发或补发事由及平台的其他要求。

::: warning 不在本站维护试点城市名单
试点范围和资格条件可能调整。请直接查看
[官方试点通知](https://s.nia.gov.cn/mps/tztg/202511/t20251110_1009.html) 和
[网上申请须知](https://s.nia.gov.cn/mps/views/hbf/hbf-sqxz.html)，以平台实时资格校验结果为准。
:::

## 官方核实入口

- [国家移民管理局官网](https://www.nia.gov.cn/)：查询护照政策、公告和收费标准。
- [国家移民管理局政务服务平台](https://s.nia.gov.cn/)：查询办证机构、预约、进度和线上业务。
- **12367 出入境管理服务热线**：咨询当地预约、照片、异地办理和补充材料要求。

:::
