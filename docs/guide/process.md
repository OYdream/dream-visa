# 递签全流程总览

> 从零到拿回护照，一共七个环节。每个环节的详细操作页正在建设中（待放）。

## 流程时间线

```
① 确定国家/领区 → ② 准备材料 → ③ 在线填表 → ④ 预约递签slot
→ ⑤ 现场递签（录指纹/拍照） → ⑥ 等待审理 → ⑦ 出签取护照
```

## ① 确定国家与领区

按「主要行程国家」确定送签国（规则见 [申根旅游签](/encyclopedia/schengen/tourist)），
再按**户籍/常住地**划分领区，选择对应签证中心递签。

::: warning 常见错误
人在上海工作、户籍在广东，按常住地应递广州/上海领区——
**用工作居住地领区**，需准备居住证等常住证明。
:::

## ② 准备材料

核心材料分四类，逐项规格见 → [材料准备](/guide/documents)

1. 身份类：护照、照片、身份证、户口本
2. 职业类：在职证明、营业执照、学生证/在读证明
3. 财力类：银行流水、存款证明、固定资产
4. 行程类：机票预订单、酒店预订单、行程单、保险

## ③ 在线填表

在送签国使领馆或签证中心官网在线填写申请表，核对无误后打印签字。
**信息必须与材料完全一致**，一处矛盾都可能被要求补材料或拒签。

## ④ 预约递签 slot

旺季 slot 开放即抢，建议：
- 关注签证中心放号时间（多在凌晨/清晨）
- 手边备好护照信息，抢到立刻填
- 没抢到可隔天再刷，取消位会回池

## ⑤ 现场递签

带齐全部材料原件+复印件，提前 15 分钟到场。
现场录指纹（十指）+ 现场拍照，材料逐项核对后签字确认。

## ⑥ 等待审理

- 一般 15 个自然日出结果，旺季可延长
- 部分国家官网可查进度（输入受理号）
- 可能被电话调查：单位、行程细节要能对答如流

## ⑦ 出签取护照

- **出签**：按选择方式取护照（自取/邮寄），当场核对签证页信息
- **拒签**：护照附拒签信，标注拒签条款，见 → [常见拒签原因](/guide/refusal)
