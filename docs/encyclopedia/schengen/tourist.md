## 申根签证是什么

申根签证（Schengen Visa）是前往【申根区 29 国】短期停留的统一签证，
持一国签证可在有效期内自由通行全部成员国。

主要出行目的为旅游、探亲访友、商务考察时，申请 **C 类短期签证**，
单次停留一般不超过 **90 天**（任意 180 天内）。

## 核心参数速览

| 参数 | 内容 |
|---|---|
| 签证类型 | C 类短期停留签证 |
| 停留期 | 任意 180 天内累计不超过 90 天 |
| 有效期 | 按行程批，常见 30 天～5 年多次 |
| 入境次数 | 单次 / 两次 / 多次（按批） |
| 受理时长 | 一般 15 个自然日，旺季可延长至 45 天 |
| 费用 | 签证费 90 欧元 + 签证中心服务费（约 19～25 欧元，按中心） |

## 主要行程国家怎么定

**向停留时间最长的国家申请**；若停留时间相同，向**首入国**申请。

举例：行程为法国 5 天 + 意大利 3 天 → 申请法国签证；
法国 3 天 + 意大利 3 天（意大利首入）→ 申请意大利签证。

## 常见问题

### 白本护照能办申根吗？

可以。白本（无任何出境记录）不是拒签理由，关键是行程合理、材料真实、
约束力证明充分（在职、流水、固定资产）。

### 要提前多久申请？

最早可在出行前 **6 个月** 递交，建议提前 **1～2 个月**，
避开旺季（暑期、春节）高峰期预约紧张时段。

### 被拒了怎么办？

先申请拒签信调档了解理由，针对性补强材料后可再次申请。
详见 → [常见拒签原因](/guide/refusal)
